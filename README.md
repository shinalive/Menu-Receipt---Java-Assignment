
# Java Basic Assignment

## Overview

This repository contains Java coursework completed as part of my Information Systems studies.

The project demonstrates basic programming concepts and the implementation of assignment requirements using Java.

## Objectives

- Practice programming fundamentals.
- Translate problem statements into working code.
- Improve logical thinking and problem-solving skills.

## Technologies

- Java
- IntelliJ IDEA

## Project Structure

This project contains two java files : **Menu.java**, and **Main.java**.

- **Menu.java** defines the menu items displayed in the application and contains the classes used to represent them.

- **Main.java** contains the functions responsible for calculating the receipt total and displaying the final receipt to the customer.

## How to Run

1. Open the project in IntelliJ IDEA.
2. Ensure that a compatible JDK is configured.
3. Open the main Java file.
4. Run the `main` method.
